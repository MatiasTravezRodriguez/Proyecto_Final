Lenguajes Y paradigmas de programacion

Los lenguajes y paradigmas de programación son los idiomas e ideales de diseño que determinan cómo los programadores estructuran, escriben y organizan el código para construir software.

Sus características principales son:

  • Abstracción del hardware: Permiten a los desarrolladores escribir lógica en un lenguaje comprensible sin gestionar directamente los circuitos del procesador.
  • Diversidad de enfoques (Paradigmas): Agrupan estilos de programación según la lógica deseada, como el imperativo (paso a paso), orientado a objetos (modelado por entidades) o funcional (evaluación de funciones puras).
  • Sintaxis y reglas estrictas: Exigen normas gramaticales fijas para ser interpretados o compilados correctamente por la computadora.
  • Reutilización y escalabilidad: Facilitan la organización del código en módulos para construir sistemas complejos, mantenibles y colaborativos.
2
Introduccion a python

La introducción a Python abarca el estudio de este lenguaje de programación de alto nivel, conocido por su sintaxis limpia, legibilidad y versatilidad en el desarrollo de software actual.

Sus características principales son:

  • Sintaxis limpia y legible: Utiliza sangrías (indentación) en lugar de llaves para delimitar bloques de código, haciendo que parezca inglés escrito.
  • Multiparadigma y multipropósito: Soporta programación orientada a objetos, imperativa y funcional, sirviendo para desarrollo web, ciencia de datos, inteligencia artificial y automatización.
  • Interpretado y dinámico: No requiere compilación previa para ejecutarse y detecta los tipos de datos automáticamente en tiempo de ejecución.
  • Ecosistema masivo: Cuenta con una biblioteca estándar muy completa y miles de librerías externas creadas por su comunidad.
3
Operaciones algebraicas, relacionales y logicas

Las operaciones algebraicas, relacionales y lógicas son las reglas fundamentales que permiten manipular datos, realizar cálculos y tomar decisiones automáticas dentro de un programa.

Sus características principales son:

  • Operaciones Algebraicas (Aritméticas): Ejecutan cálculos matemáticos estándar (como suma +, resta -, multiplicación * o módulo %) y devuelven un resultado numérico.
  • Operaciones Relacionales (Comparativas): Evalúan la relación entre dos valores (como mayor que >, igual a == o diferente de !=) para comprobar condiciones.
  • Operaciones Lógicas (Booleanas): Combinan o invierten estados de verdad mediante operadores (como AND, OR y NOT) para construir reglas de decisión complejas.
  • Retorno Verdadero/Falso (Booleanos): Salvo las algebraicas, las operaciones relacionales y lógicas siempre devuelven como resultado final un valor booleano: Verdadero (True) o Falso (False).
4
Estructuras de control condicionales

Las estructuras de control condicionales son instrucciones que permiten alterar el flujo de ejecución de un programa, evaluando una condición para decidir qué bloque de código ejecutar.

Sus características principales son:

  • Toma de decisiones: Evalúan una expresión lógica o relacional para elegir entre caminos de ejecución alternativos.
  • Evaluación booleana: Su funcionamiento se basa estrictamente en un resultado de Verdadero (True) o Falso (False).
  • Bifurcación del flujo: Permiten omitir o ejecutar secciones enteras de código según se cumplan o no los criterios definidos.
  • Variedad de formas: Incluyen estructuras simples (Si / if), dobles (Si-Sino / if-else), múltiples (Si-SinoSi / elif) y de selección múltiple por casos (Según / switch).
5
Estructuras de control repetitivas

Las estructuras de control repetitivas (o bucles) son instrucciones que permiten ejecutar un mismo bloque de código de forma cíclica mientras se cumpla una condición determinada.

Sus características principales son:

  • Automatización de tareas: Evitan la repetición manual de código ejecutando iteraciones sucesivas.
  • Control por condición: Utilizan expresiones lógicas para determinar cuándo continuar o detener las repeticiones (previniendo bucles infinitos).
  • Tipos por uso: Se dividen en iteraciones definidas por conteo (Para / for) e iteraciones sujetas a condiciones dinámicas (Mientras / while).
  • Manejo de variables de control: Emplean contadores o banderas para rastrear el progreso de cada ciclo y evaluar la condición de parada.
