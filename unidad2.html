Algoritmos y sus caracteristicas

Un algoritmo es una secuencia finita, ordenada y precisa de pasos para resolver un problema o ejecutar una tarea.

Sus características principales son:

  • Finito: Tiene un inicio y un final tras un número determinado de pasos.
  • Preciso: Cada paso debe indicar exactamente qué hacer, sin ambigüedades.
  • Definido: Produce siempre el mismo resultado frente a las mismas entradas.
  • Entrada y Salida: Recibe datos de inicio y genera una respuesta o solución concreta.
2
Diagramas de flujo

Un diagrama de flujo es la representación gráfica de un algoritmo, utilizada para visualizar la secuencia de pasos de un proceso mediante símbolos estandarizados.

Sus características principales son:

  • Símbolos estándar: Usa figuras geométricas específicas (óvalos para inicio/fin, rectángulos para procesos, rombos para decisiones).
  • Flujo unidireccional: Muestra el orden de lectura mediante líneas y flechas que conectan los pasos.
  • Sintético y claro: Reduce la lógica compleja a una estructura visual fácil de entender de un vistazo.
  • Estructurado: Solo tiene un punto de entrada de inicio y un punto final.
3
Pseudocodigo

El pseudocódigo es la representación escrita de un algoritmo que utiliza lenguaje humano estructurado para describir la lógica de un programa sin seguir la sintaxis estricta de un lenguaje de programación.

Sus características principales son:

  • Lenguaje intermedio: Se ubica entre el lenguaje natural y el código de programación real.
  • Flexible pero legible: No exige una sintaxis rigurosa, priorizando la claridad y la comprensión lógica.
  • Estructurado: Emplea palabras clave estándar (como Inicio, Fin, Si-Entonces, Mientras) para marcar el flujo del algoritmo.
  • Fácil de traducir: Sirve como borrador directo para escribir el programa final en cualquier lenguaje (Python, C++, Java, etc.).
4
Modelado de problemas

El modelado de problemas es la técnica de abstraer un escenario del mundo real para convertirlo en un esquema simplificado y estructurado que un algoritmo o sistema pueda resolver.

Sus características principales son:

  • Abstracción: Selecciona únicamente los datos y reglas relevantes del problema, ignorando los detalles innecesarios.
  • Representación formal: Transforma una situación abstracta en variables, ecuaciones, gráficos o diagramas definidos.
  • Delimitación de alcance: Establece con claridad los límites, restricciones y objetivos que debe cumplir la solución.
  • Base para la solución: Sirve como el diseño previo fundamental antes de escribir pseudocódigo o desarrollar el software.
